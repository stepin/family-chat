A family chat on your own server

Family Chat: your family's messages on a program that runs in your home. Messages are encrypted on the phone; the server stores only ciphertext.

For one family, from two to twenty people. An administrator (usually one of the parents) runs the server, everybody else joins with an invitation link. No phone number and no app store: the app opens in the browser and installs on the phone's home screen. The app speaks English and Russian.

What it does and does not do

It does

  • Direct chats, groups and "Saved messages" for notes to yourself.
  • Photos, files up to 200 MB (the administrator sets the limit), voice messages up to 10 minutes, places without loading a map.
  • Replies, edits, delete for everyone, reactions, emoji, stickers, forwarding.
  • Search through the history. It runs on the device; the query goes nowhere.
  • Notifications about new messages (Web Push). On iPhone only for the app on the home screen.
  • End-to-end encryption: text, files and group names are encrypted on the device.
  • Several families (servers) in one app.
  • Works on iPhone, Android and computers as a web app (PWA).

It does not do or promise

  • No calls or video calls. No read receipts and no "typing…".
  • The server keeps messages for at most 90 days (or less). Everything older lives only on devices and in archive files.
  • Lost a phone without the 24 recovery words and without an archive: the older history is gone.
  • Whoever runs the server sees who writes to whom and when (but not what). The app is loaded from their server, so they can technically replace it.
  • No forward secrecy: a stolen device reveals what is on the server and its own archive.
  • The server does not obtain an HTTPS certificate by itself: you need a reverse proxy, a router with HTTPS, or your own certificate files.
  • One device gets notifications from one family only.

In detail, what the server sees and what encryption does not protect: Security.

How it works

  1. A server at home. One program, fcd, and one data folder, no database. Any computer that runs around the clock will do: a mini PC, NAS, Raspberry Pi, home server or VPS. There are builds for Linux (x86_64, ARM64, ARMv7), macOS, Windows and a Docker image.
  2. HTTPS. The browser requires a secure connection for encryption, notifications and installing the app. Usually a reverse proxy provides it (Caddy, nginx, a NAS, a router).
  3. The family. The administrator opens the server address, enters the code from the server log, writes down the 24 recovery words and creates invitations. Each invitation works for one person for 7 days.
  4. Chatting. A relative opens the link, installs the app, enters a name and writes. History lives on their device; the server passes on what is new and deletes it after 90 days.
