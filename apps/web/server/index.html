Проверка сервера

Сервер отвечает, длинный запрос проходит, уведомления доходят. Пройдите проверки с ноутбука и с каждого телефона, дома и в мобильной сети, затем скопируйте отчёт. До настройки проверки идут по коду администратора; после входа первого администратора проверяйте сервер в приложении: Настройки → Семья и сервер → Проверка сервера.
