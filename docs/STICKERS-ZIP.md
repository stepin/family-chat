# Набор стикеров Telegram в архив .zip

Скрипт [`tools/telegram-stickers-zip.py`](tools/telegram-stickers-zip.py) скачивает набор стикеров Telegram в архив
`.zip`, который Family Chat принимает как новый набор («Настройки», «Наборы стикеров», «Добавить набор»). Пригодится,
если на сервере семьи не задан токен бота и ссылка `https://t.me/addstickers/…` в приложении не работает, или если
набор нужно поправить перед публикацией: убрать лишние стикеры, поменять эмодзи.

English: [en/STICKERS-ZIP.md](en/STICKERS-ZIP.md).

## Что нужно

- Python 3.8 или новее. Других библиотек не нужно.
- Токен бота Telegram. Telegram отдаёт наборы только через Bot API, поэтому без бота скачать набор нельзя. Бота
  создаёт @BotFather: отправьте ему `/newbot`, задайте имя и получите токен вида `123456:ABC…`. Боту ничего не
  нужно разрешать, и писать ему не надо. Подойдёт и бот, токен которого уже задан серверу `fcd`.

Токен работает как пароль: не публикуйте его и не сохраняйте в репозитории. Если токен попал в чужие руки,
отзовите его в @BotFather (`/revoke`).

## Как запустить

```sh
export TELEGRAM_BOT_TOKEN='123456:ABC...'
python3 docs/tools/telegram-stickers-zip.py https://t.me/addstickers/Mewrio
```

Получится `Mewrio.zip` в текущей папке. Если переменная `TELEGRAM_BOT_TOKEN` не задана, скрипт спросит токен при
запуске, ввод не отображается. Переменная `FCD_TELEGRAM_BOT_TOKEN`, которую читает сервер, тоже подходит.

Вместо ссылки можно дать имя набора (`Mewrio`) или ссылку вида `tg://addstickers?set=Mewrio`.
Ссылку с `?` берите в кавычки, иначе zsh примет её за шаблон имён файлов.

| Параметр | Что делает |
| --- | --- |
| `-o`, `--output <файл>` | куда записать архив (по умолчанию `<имя набора>.zip` в текущей папке) |
| `-f`, `--force` | перезаписать архив, если он уже есть |

Пример вывода:

```
Mewrio: 39 stickers
  1/39 🤨
  2/39 🤪
  ...
Mewrio.zip: 39 stickers, 1139 KB
```

Затем в приложении: «Настройки», «Наборы стикеров», «Добавить набор», «Выбрать файлы», выберите архив, проверьте
предпросмотр и название, «Опубликовать для семьи». Набор увидят все в семье. Стикеры хранятся на сервере без
шифрования.

## Что в архиве

- Файлы `.webp` (обычные стикеры) и `.tgs` (анимированные) в порядке набора.
- Имена вида `<эмодзи>_<номер>.<расширение>`, например `🤨_01.webp`. Эмодзи стикера приложение берёт из первого
  символа имени файла, поэтому эмодзи из Telegram сохраняются. Если переименовать файл так, чтобы имя начиналось
  не с эмодзи, у стикера будет 🙂.
- Видеостикеры (`.webm`) пропускаются: приложение их пока не поддерживает. Набор только из видеостикеров скачать
  нельзя, скрипт так и скажет. Наборы эмодзи Telegram (custom emoji) тоже не скачиваются.

## Если хотите собрать архив сами

Архив можно собрать и без скрипта, из любых своих файлов. Приложение проверяет его на устройстве перед
предпросмотром:

- внутри только `.webp` (статичные или анимированные) и `.tgs`; другие файлы пропускаются, архив внутри архива
  отвергается целиком; `__MACOSX/`, `.DS_Store`, `Thumbs.db` и `desktop.ini` не мешают;
- в наборе от 1 до 200 стикеров, `.webp` до 512 КБ, `.tgs` до 128 КБ, стороны от 1 до 1024 точек, всего до 50 МБ;
- стикеры идут в порядке файлов в архиве, одинаковые файлы считаются один раз;
- обычный zip со сжатием deflate или без сжатия; без пароля, без ZIP64 и без разбиения на тома;
- `.tgs` длиннее 10 секунд, с частотой больше 120 кадров в секунду или с распакованным JSON больше 1 МБ не
  принимается.

Из папки со стикерами архив собирается так (macOS и Linux):

```sh
cd стикеры && zip -X ../набор.zip *.webp *.tgs
```

## Ошибки

| Сообщение | Что делать |
| --- | --- |
| `getStickerSet: Unauthorized (check the bot token)` | токен неверный или отозван: возьмите новый в @BotFather |
| `getStickerSet: Bad Request: STICKERSET_INVALID` | набора с таким именем нет: проверьте ссылку |
| `... is a set of custom emoji, not stickers` | это набор эмодзи, приложение принимает только стикеры |
| `no stickers the app can import` | в наборе только видеостикеры |
| `<файл> exists (use --force to overwrite)` | архив уже есть: укажите другое имя через `-o` или добавьте `--force` |
| `getFile: <причина сети>` | Telegram недоступен: проверьте сеть и запустите ещё раз |
