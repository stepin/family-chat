# Изменения

Формат: разделы по версиям, новые сверху. Нумерация версий [SemVer](https://semver.org/lang/ru/); до 1.0 формат
данных и API могут меняться, но сервер обновляет папку данных старой версии сам.

## [1.1.0] 20.11.2026

### Новое

- **ИИ-помощники (MCP).** К семье можно подключить ИИ-помощника, например Claude: он читает и пишет сообщения, ведёт
  группы, отправляет файлы и стикеры, а администратору помогает с приглашениями. Всё встроено в `fcd`: адрес
  `https://<сервер>/mcp`, отдельной программы или порта нет. Подробности: [docs/MCP.md](docs/MCP.md).
  - Два вида подключений: **помощник со своей личностью** (его создаёт администратор семьи, это отдельный участник
    со своим именем) и **моя личность** (любой участник подключает помощника к себе, и тот пишет от его имени).
  - Экран **«Настройки → ИИ-помощники»**: создание, разрешения, новый токен, удаление. Токен показывается один раз,
    вместе с адресом и готовой командой для Claude Code.
  - **Разрешения** по каждому подключению: чтение и запись включены, файлы, администрирование и необратимое
    включает человек. Через MCP их изменить нельзя.
  - Файлы до 1 МБ передаются прямо в запросе, большие по одноразовым ссылкам. Из фотографий перед отправкой
    убираются место и время съёмки.
  - Протокол MCP ревизии 2026-07-28 и прежних (с `initialize`); вход по токену в заголовке.
- **Важно для доверия.** Чтобы действовать за личность, сервер хранит её ключ и может читать её переписку. Это
  касается только подключённых личностей и только по решению человека; у остальных всё как раньше. В профиле
  участника, к личности которого подключён помощник, приложение показывает пометку. Раздел «ИИ-помощники (MCP)» в
  [docs/SECURITY-MODEL.md](docs/SECURITY-MODEL.md).
- Настройка сервера `mcp` (`--mcp`, `FCD_MCP`), по умолчанию включена. `mcp = false` выключает адрес `/mcp` и экран.
- В API: `mcp` в `GET /v1/hello`, поле `mcp` у участника в `GET /v1/users`, запросы `/v1/mcp` (раздел 10b в
  [docs/API.md](docs/API.md)).
- На сайте: страница «ИИ-помощники (MCP)» на русском и английском и раздел о них на главной, со снимком экрана
  разрешений.

### Изменено

- **В «Избранном» удалённая заметка просто исчезает.** Строки «Сообщение удалено» там больше нет, а в списке чатов
  под «Избранным» показывается предыдущая заметка.
- Новый вид сайта: тёплые цвета и панорама кухни на главной.

### Исправлено

- **`fcd` останавливается штатно сразу после запуска.** Раньше SIGINT/SIGTERM сразу после строки «listening on»
  (например, быстрый `docker stop`) убивал процесс вместо штатной остановки.

### Обновление с 1.0.1

Замените `fcd` и перезапустите; формат папки данных не изменился. В папке данных семьи появится папка `mcp/`, когда
кто-нибудь создаст первое подключение: в ней лежат ключи подключённых личностей, поэтому резервную копию храните так
же бережно, как сам сервер. Если ИИ-помощники не нужны, добавьте `mcp = false` в `config.toml`. За обратным прокси
проверьте, что он передаёт `X-Forwarded-Proto` и держит запрос не меньше 60 секунд.

### Что проверено

Модульные и интеграционные тесты сервера (в том числе сверка реализации протокола на Rust с `docs/vectors/`),
тесты ядра и приложения, работа приложения и MCP друг с другом на настоящем `fcd` (личные чаты, группы, файлы,
подключение своей личности), экран в Chromium с проверкой доступности. С настоящими клиентами MCP (Claude Code и
другими) перед выпуском проверьте вручную: в тестах клиента MCP изображает сам тест.

## [1.0.1] 17.11.2026

### Исправлено

- **Свои сообщения больше не присылают уведомлений.** Уведомление получают только устройства других участников
  чата: ни устройство, с которого написано сообщение, ни другие устройства автора, ни «Избранное». В 1.0.0 браузер,
  где открыто несколько аккаунтов одного сервера, получал уведомление о сообщении, которое в нём же и написали.
  Исправление на сервере, приложение обновлять не нужно.

### Новое

- Скрипт `docs/tools/telegram-stickers-zip.py` скачивает набор стикеров Telegram в `.zip`, который приложение
  принимает как новый набор (docs/STICKERS-ZIP.md).

### Обновление с 1.0.0

Замените `fcd` и перезапустите; формат папки данных и настройки не изменились.

## [1.0.0] 17.11.2026

Первая публичная версия.

### Новое

- **Несколько семей на одном сервере.** Один `fcd` держит несколько семей: корневая по адресу сервера, другие по
  адресам `https://<сервер>/f/<id>` со своими участниками, кодами и данными. Семью создают в приложении кодом
  администратора сервера («Настроить для своей семьи» или «Добавить семью», «Я администратор: новая семья»);
  `fcd families list` показывает семьи сервера, `--family <id>` у `reset-admin-code`, `admin list` и `admin add`
  выбирает семью, `fcd healthcheck --strict` учитывает сломанные семьи. Подписи семей одного сервера в приложении
  различаются адресом (`хост · /f/abcd…`).
- **Уведомления от всех семей одного сервера.** Один service worker на сервер и одна подписка браузера на все его
  семьи; включаются сразу для семей сервера, выключаются для каждой отдельно; заголовок уведомления начинается с
  имени семьи, когда семей на устройстве несколько.
- **Наборы стикеров Telegram по ссылке** `https://t.me/addstickers/…` в «Наборах стикеров», если администратор задал
  токен бота (`--telegram-bot-token`, файл или `FCD_TELEGRAM_BOT_TOKEN`, см. docs/ADMIN.md#telegram). Видеостикеры
  пока пропускаются. Токен хранит сервер и никогда не пишет в журнал и новый `config.toml`.

### Изменено

- **Эмодзи из панели больше не уходит случайно отдельным сообщением:** он всегда встаёт в поле туда, где курсор, и
  отправляется как обычный текст. На телефоне клавиатура при этом не открывается.
- **Код администратора сервера теперь постоянный** (многоразовый): он только создаёт семьи и не даёт входа в семью.
  У каждой семьи свой одноразовый код входа: код настройки (1 час) или код восстановления
  (`fcd reset-admin-code --family <id|root>`). Для создания семей на уже настроенном сервере один раз выполните
  `fcd reset-admin-code` при остановленном сервере.
- **`--offer-setup` удалён, строку `offer_setup` из `config.toml` удалите** перед запуском 1.0.0 (иначе сервер
  остановится с ошибкой, которая называет эту строку). «Настроить для своей семьи» первый экран показывает всегда.
- Поле `offerSetup` в `/v1/hello` оставлено на этот выпуск (всегда `true`) для уже установленных приложений 0.1.0;
  добавлены `rootSetUp` и `telegramStickers`.
- Приложения версии 0.1.0 до обновления работают с сервером 1.0.0, но про несколько семей одного сервера не знают:
  уведомления от семей одного сервера у них по-прежнему приходят только от одной.

### Обновление с 0.1.0

Сделайте резервную копию, удалите строку `offer_setup` из `config.toml`, запустите 1.0.0, затем один раз
`fcd reset-admin-code` (при остановленном сервере). Корневая семья и её данные остаются как были; формат папки
данных не изменился (папку `families/` старый сервер не видит).
